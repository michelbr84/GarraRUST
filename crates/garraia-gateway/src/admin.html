Sign in to the Admin Console

Esqueci minha senha

Sem e-mail. O codigo de recuperacao e gerado no servidor e entregue para quem tem acesso ao terminal da maquina — e ninguem mais.

Rode no host onde o GarraIA esta instalado:

garra admin recovery start --username SEU_USUARIO

O comando mostra o codigo (que vale 10 minutos e serve uma unica vez). Depois:

garra admin recovery complete --username SEU_USUARIO --code CODIGO

Se o terminal nao for na mesma maquina do gateway, o codigo fica em admin-recovery.code, dentro do diretorio de dados.
