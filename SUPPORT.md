# Suporte

Precisa de ajuda com o GarraIA? Use o canal certo:

| Preciso de… | Onde |
|---|---|
| Documentação e primeiros passos | [Wiki](https://github.com/michelbr84/GarraRUST/wiki) · [garraia.org/docs](https://garraia.org/docs/introducao) · [`docs/`](docs/) |
| Tirar uma dúvida / trocar ideia | [GitHub Discussions](https://github.com/michelbr84/GarraRUST/discussions) |
| Conversar com a comunidade | [Discord](https://discord.gg/aEXGq5cS) |
| Reportar um bug ou pedir uma feature | [Abrir issue](https://github.com/michelbr84/GarraRUST/issues/new/choose) (use os templates) |
| Reportar uma **vulnerabilidade de segurança** | **Nunca em issue pública** — siga o [SECURITY.md](SECURITY.md) (advisory privado ou security@garraia.org) |
| Contribuir com código | [CONTRIBUTING.md](CONTRIBUTING.md) — comece pelas [good first issues](https://github.com/michelbr84/GarraRUST/issues?q=label%3Agood-first-issue+is%3Aopen) |

Antes de abrir uma issue, vale conferir se já existe uma parecida (aberta ou
fechada) e rodar `garra config check` / `garra verify` — a saída deles ajuda
muito no diagnóstico.
