# Suporte

Precisa de ajuda com o GarraIA? Use o canal certo:

| Preciso de… | Onde |
|---|---|
| Documentação e primeiros passos | [Wiki](https://github.com/michelbr84/GarraRUST/wiki) · [garraia.org/docs](https://garraia.org/docs/introducao) · [`docs/`](docs/) |
| Política de suporte, versões e depreciação | [`docs/operations/support-policy.md`](docs/operations/support-policy.md) · [`version-support-policy.md`](docs/operations/version-support-policy.md) · [`deprecation-policy.md`](docs/operations/deprecation-policy.md) — **propostas**, aguardam ratificação |
| SLA | **Sem SLA contratual hoje** — self-host roda na sua infra; o Garra Cloud (planejado) também launcha sem promessa numérica de uptime, comunicando disponibilidade de forma clara. SLA numérico, se existir, será só em contrato enterprise — decisão e opções em [`docs/operations/sla-decision-brief.md`](docs/operations/sla-decision-brief.md) |
| Tirar uma dúvida / trocar ideia | [GitHub Discussions](https://github.com/michelbr84/GarraRUST/discussions) |
| Conversar com a comunidade | [Discord](https://discord.gg/aEXGq5cS) |
| Reportar um bug ou pedir uma feature | [Abrir issue](https://github.com/michelbr84/GarraRUST/issues/new/choose) (use os templates) |
| Sou cliente Garra Cloud (beta) — atendimento prioritário | Canal privado do painel do cliente e/ou canal oficial do projeto — `[PENDENTE: confirmar operação do canal/caixa antes de anunciar]` |
| Pedidos de titular de dados (LGPD) ou incidentes de segurança | Atendidos **por gravidade, independentemente do plano** (inclusive free/comunidade) — dados pessoais, credenciais e vulnerabilidades **nunca** em canal público; use o canal privado do [SECURITY.md](SECURITY.md) ou o canal de titulares `[PENDENTE: caixa/fluxo de pedidos de titulares a confirmar antes de anunciar]` |
| Reportar uma **vulnerabilidade de segurança** | **Nunca em issue pública** — siga o [SECURITY.md](SECURITY.md) (advisory privado ou security@garraia.org) |
| Contribuir como usuário (bug, dúvida, feature) | [`docs/operations/user-contribution-guide.md`](docs/operations/user-contribution-guide.md) — pré-flight, templates e canais |
| Contribuir com código | [CONTRIBUTING.md](CONTRIBUTING.md) — comece pelas [good first issues](https://github.com/michelbr84/GarraRUST/issues?q=label%3Agood-first-issue+is%3Aopen) |

Antes de abrir uma issue, vale conferir se já existe uma parecida (aberta ou
fechada) e rodar `garra config check` / `garra verify` — a saída deles ajuda
muito no diagnóstico.
