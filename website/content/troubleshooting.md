# Troubleshooting

Esta página só agrega os pontos de solução de problemas que **já existem** nas
seções reais da documentação. Cada link leva direto à seção correspondente.

- **Instalação** — erros ao instalar ou compilar: veja
  [Instalação → Troubleshooting](/instalacao/installation#troubleshooting).
- **Gateway / deploy** — servidor que não sobe, portas, variáveis de ambiente:
  [Deployment → Solução de Problemas](/gateway/deployment#solução-de-problemas)
  (inclui [erros de chave de API](/gateway/deployment#erros-de-chave-de-api)).
- **Perfis de execução** — pod isolado, raiz do MCP filesystem, boot recusado:
  [Perfis de execução → Troubleshooting](/gateway/execution-profiles#troubleshooting).
- **MCP** — handshake, tools que não aparecem, stdio vs HTTP:
  [MCP → Troubleshooting](/mcp#troubleshooting).
- **WhatsApp** — pareamento, dispositivo vinculado, política de acesso:
  [WhatsApp → Troubleshooting](/whatsapp#troubleshooting).
- **Voz (STT/TTS)** — servidores locais de voz, diagnósticos:
  [Voz → Diagnostics](/api/voice#diagnostics) e
  [Voz → Troubleshooting](/api/voice#troubleshooting).

Não achou o seu caso? O [config check](/configuracao/configuration) e o
`garra config check` apontam problemas de configuração com o próximo passo
sugerido, e as [issues no GitHub](https://github.com/michelbr84/GarraRUST/issues)
são o canal para relatar algo novo.
